Koshakan Smart POS Agent — portable Windows version

1. Распакуйте весь ZIP-архив в отдельную папку.
2. Не запускайте EXE прямо из ZIP-архива.
3. Запустите KoshakanSmartPosAgent.exe.
4. Пройдите первичную настройку и сохраните CRM Agent Token.
5. На Smart POS разрешите запрос регистрации клиента.
6. После запуска значок агента появится рядом с часами Windows.

Windows SmartScreen может показать предупреждение: эта сборка пока не подписана
цифровым сертификатом. Убедитесь, что архив получен со страницы GitHub Releases
проекта, и распакуйте его полностью перед запуском.
