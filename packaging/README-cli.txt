Koshakan Smart POS Agent CLI — portable Windows diagnostics

Распакуйте весь ZIP-архив и запускайте KoshakanSmartPosAgentCli.exe из
распакованной папки. Для списка технических команд выполните:

  KoshakanSmartPosAgentCli.exe --help

CLI предназначен для диагностики; для ежедневной работы используйте tray-приложение.
