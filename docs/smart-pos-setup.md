# Настройка Smart POS

1. Подключите Windows-компьютер администратора и Smart POS к одной приватной LAN.
2. Закрепите за терминалом статический IP / DHCP reservation.
3. Проверьте, что порт `8080` доступен с компьютера, но не публикуйте его в интернет.
4. В `.env` укажите IP в `SMART_POS_HOST`, имя клиента и TLS-режим. API всегда вызывается по HTTPS.
5. Запустите `python -m smart_pos_agent register` и подтвердите запрос на терминале.
6. Выполните `device-info`, затем только контролируемую проверочную оплату на 10 ₸.

`strict` использует стандартную проверку TLS; `custom_ca` требует путь к CA bundle; `ip_insecure` допустим лишь как явно установленный параметр при обращении по IP и пишет warning в лог. Никогда не переносите accessToken/refreshToken в `.env`, логи, базу или CRM.
