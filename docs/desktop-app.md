# Windows tray-приложение

`KoshakanSmartPosAgent.exe` запускает Qt desktop-слой поверх существующего ядра. Qt не импортируется core-модулями: `AgentRuntime` создаёт единственный `Application` в отдельном Python thread с собственным asyncio loop. Команды из UI попадают туда через `asyncio.run_coroutine_threadsafe`, поэтому запросы CRM и Smart POS не блокируют Qt event loop.

`AgentUiState` — типизированная проекция событий CRM, heartbeat, device-info и операций. Окно и tray не разбирают строки логов. Callback наблюдения не изменяет protocolVersion или полезную нагрузку WebSocket-сообщений; дополнительные поля статуса операции являются обратно совместимыми.

При первом запуске мастер создаёт persistent несекретный config и помещает CRM Agent Token в `SecretStore`. При следующем запуске окно может быть скрыто настройкой `start_minimized`. Повторный GUI-процесс не получает SQLite: `QLockFile` не позволяет ему создать второй runtime и показывает понятное сообщение.

Трей показывает уведомления о завершении/ошибке операции, недоступном терминале и `manual_review`. Повторяющиеся уведомления подавляются на 30 секунд. Закрытие главного окна скрывает его; «Выход» при активной операции требует дополнительного подтверждения с фокусом на «Не выходить».

Автозапуск создаётся только для packaged GUI EXE через Task Scheduler текущего пользователя. В task action нет токенов и аргументов.
